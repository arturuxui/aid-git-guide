# Git for Beginners — контекст для Claude

Гайд по git «для чайников»: после него человек, впервые взявшийся за git, работает с ветками, PR, merge и CI
и говорит с командой на одном языке, а потом возвращается к гайду за подсказками. Два результата из одного
источника: интерактивная веб-версия (для Presentbook AID) и документ (PDF).

Общаемся по-русски. Пользователь — инженер Library Updater, владелец этого продукта и его первый читатель
(тестовый новичок); объяснять простыми словами.

## Правила содержания

- Читатель — новичок. Каждое действие показываем двумя путями: **где нажать в GitHub** и **что сказать Claude**;
  git-команда — мелко, для понимания. Командная строка — минимум.
- Только русский; английский термин — рядом при первом упоминании и в глоссарии (интерфейс GitHub — английский).
- rebase, cherry-pick, worktree, цепочки PR — только в главе «Продвинутое»; основная часть без них обходится.
- В каждой главе: абстрактный пример и блок «Как это в AID» со ссылкой на источник и датой сверки.

## Git

- `main` всегда рабочий, напрямую в него не коммитим.
- Одна задача — одна ветка → PR в `main` → CI зелёный → пользователь сливает через **Squash and merge**.
- `gh` установлен в `C:\Program Files\GitHub CLI` и может отсутствовать в `PATH` Bash:
  `export PATH="$PATH:/c/Program Files/GitHub CLI"`.
