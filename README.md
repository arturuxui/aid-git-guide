# AID · Guide · Git for Beginners

Гайд по git для новичков: ветки, push, PR, merge, CI и работа в команде. Интерактивная веб-версия и документ из одного источника.

План — [docs/PLAN.md](docs/PLAN.md). Главы — [content/ru/](content/ru/00-intro.md); веб-версию собирает Presentbook AID.

- `npm run check` — главы соберутся в Presentbook без правок.
- `npm run pdf` — выгружаемая копия: `dist/git-for-beginners.pdf` (Chromium: `npx puppeteer browsers install chrome`).
  Готовый PDF — в [Releases](https://github.com/arturuxui/aid-git-guide/releases/latest).
