# Глоссарий

Слова, которые говорят в команде, и что за ними стоит. В скобках — английский
оригинал, как на экране GitHub или в ответе Claude. Черновик: в веб-версии станет
поиском по терминам.

| Термин | Английский | Сленг | Что это | Глава |
|---|---|---|---|---|
| Репозиторий | repository | репо | папка проекта со всей историей | [1](01-why-git.md) |
| Локальный репозиторий | local | | копия репозитория на твоём компьютере | [1](01-why-git.md) |
| Удалённый репозиторий | remote | | копия на GitHub, общая для всех | [1](01-why-git.md), [4](04-remote.md) |
| Коммит | commit | закоммитить | снимок файлов с автором, временем и сообщением | [2](02-commit.md) |
| Сообщение коммита | commit message | | короткое «что и зачем» к коммиту | [2](02-commit.md) |
| Рабочая папка | working directory, working tree | | файлы на диске, которые ты правишь | [2](02-commit.md) |
| Подготовлено, индекс | staging area, index | застейджить | то, что войдёт в следующий коммит | [2](02-commit.md) |
| Разница | diff | дифф | что поменялось: красное удалено, зелёное добавлено | [2](02-commit.md) |
| История, лог | log, history | | цепочка коммитов | [2](02-commit.md) |
| Ветка | branch | бранч | отдельная линия истории; ярлычок на коммите | [3](03-branches.md) |
| Главная ветка | main (раньше master) | мейн | ветка, которую все считают правильной | [3](03-branches.md) |
| HEAD | HEAD | | «где я сейчас»: текущая ветка | [3](03-branches.md) |
| Переключиться | switch, checkout | зачекаутиться | перейти на другую ветку | [3](03-branches.md) |
| Клонировать | clone | склонировать | скачать репозиторий с GitHub целиком | [4](04-remote.md) |
| origin | origin | | обычное имя удалённого репозитория, откуда склонировано | [4](04-remote.md) |
| `origin/main` | remote-tracking branch | | `main`, как он выглядит на GitHub по последним сведениям | [4](04-remote.md) |
| Отправить | push | запушить, пушнуть | выложить свои коммиты на GitHub | [4](04-remote.md) |
| Узнать новое | fetch | зафетчить | спросить GitHub, что нового, ничего не меняя у себя | [4](04-remote.md) |
| Забрать | pull | спуллить, подтянуть | fetch + слияние с твоей веткой | [4](04-remote.md) |
| Впереди / позади | ahead / behind | | у тебя есть коммиты, которых нет на GitHub / наоборот | [4](04-remote.md) |
| Принудительный push | force-push | форспуш | перезаписать историю на GitHub; опасно | [4](04-remote.md) |
| Pull Request | pull request (PR) | пиар, пулл-реквест | предложение слить ветку, с обсуждением и проверками | [5](05-pull-request.md) |
| Merge Request | merge request (MR) | | то же, что PR, в GitLab | [5](05-pull-request.md) |
| Черновик PR | draft pull request | драфт | PR, который пока нельзя слить | [5](05-pull-request.md) |
| Ревью | review | | просмотр изменений коллегой | [5](05-pull-request.md) |
| Одобрить | approve | апрув, апрувнуть | «можно сливать» | [5](05-pull-request.md) |
| Запросить правки | request changes | | «до merge нужно поправить» | [5](05-pull-request.md) |
| base / compare | base / compare | | куда сливаем / откуда | [5](05-pull-request.md) |
| Слить | merge | смержить, влить | соединить ветку с другой, обычно с `main` | [6](06-merge.md) |
| Коммит слияния | merge commit | | коммит-«шов», соединяющий две ветки | [6](06-merge.md) |
| Сжать и слить | squash and merge | засквошить | все коммиты PR — одним коммитом в `main` | [6](06-merge.md) |
| Перемотка | fast-forward | | merge без шва: `main` просто сдвигается вперёд | [6](06-merge.md) |
| Конфликт | merge conflict | | двое поменяли одно место по-разному; решает человек | [6](06-merge.md) |
| CI | continuous integration | | автоматические проверки на каждый PR и push | [7](07-ci.md) |
| Проверки | checks | чеки | конкретные задачи CI: сборка, тесты, линтеры | [7](07-ci.md) |
| GitHub Actions | GitHub Actions | экшены | CI GitHub; описан в `.github/workflows/` | [7](07-ci.md) |
| Деплой | deploy | задеплоить, выкатить | публикация проекта | [7](07-ci.md) |
| Превью | preview deployment | | временная копия сайта для одного PR | [7](07-ci.md) |
| Production | production | прод | настоящий сайт для всех | [7](07-ci.md) |
| Форк | fork | форкнуть | твоя копия чужого репозитория на GitHub | [8](08-teamwork.md) |
| upstream | upstream | | обычное имя оригинального репозитория рядом с форком | [8](08-teamwork.md) |
| Issue | issue | ишью, задача | задача или вопрос в репозитории на GitHub | 10 |
| Тег | tag | | постоянная метка на коммите, обычно версия: `v1.0.0` | 9 |
| Релиз | release | | опубликованная версия с описанием и файлами | 9 |
| Rebase | rebase | ребейз, ребейзнуть | переставить коммиты ветки на новое основание | 13 |
| Cherry-pick | cherry-pick | черрипикнуть | скопировать один коммит в другую ветку | 13 |
| Worktree | worktree | | вторая рабочая папка того же репозитория на другой ветке | 13 |
| Stash | stash | застешить | отложить незакоммиченные правки на полку | 13 |

## Только в AID

| Термин | Что это |
|---|---|
| Штаб | чат Claude «AID · Hub · Штаб»: раздаёт задачи чатам продуктов, ведёт доску |
| Доска | файл `docs/hub/boards/<код>.md` или `BOARD.md`: активные задачи и решения дословно |
| PD | Principal Designer — принимает системные решения AID |
| Владелец продукта | логин GitHub из `docs/hub/owners.json`; утверждает работу и релизы своего продукта |
| Стык | место, где один продукт влияет на другой; у стыка есть владелец |
| Контур | единица деплоя: Token Comparator или Presentbook |
| Presentbook | сайт дизайн-системы AID, `aidteam.pro` |
| `AID-<n>`, `AID-LU-<n>` | номера задач на досках Штабов |
| `[TASK @логин]` | заголовок issue — задача конкретному человеку |
